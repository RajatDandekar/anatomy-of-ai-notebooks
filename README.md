# The Anatomy of AI · Notebooks

One runnable notebook for each lecture of [The Anatomy of AI](https://glass-box-sigma.vercel.app/), a visual course in mechanistic
interpretability that starts from a single neuron.

Each notebook follows its lecture plate by plate and rebuilds the results from scratch. Every key number is checked
against the lecture's own (✓ when it matches). Each notebook ends with "Your turn" exercises, with worked solutions
after them.

**To run one:**
1. Click its **Open in Colab** badge.
2. Choose *Runtime → Run all*.

Notebooks marked T4 GPU open on a GPU runtime. Each runs on free Colab in under about 20 minutes, with pinned installs
and no keys. Where a model is too big to train in Colab, the notebook downloads the course's own copy and checks its
fingerprint.

The copies here have their outputs cleared, so you run them fresh. To read a finished run with every output and
figure, follow the "read it with outputs" link.
